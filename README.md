# postman-api-practice
Individual API practice using Postman, covering HTTP requests and JSON responses.
Postman API Practice

Overview
This repository contains five individual API practice tasks completed using Postman as part of my IT Business Anslysis coursework.
The tasks involve sending requests to existing APIs and analyzing the responses.

Tasks
1. Convert Money — Converting an amount from one currency to another.
2. Margarita Recipe — Retrieving a recipe for a Margarita.
3. Weather Forecast — Retrieving current weather information.
4. Shorten the Link — Shortening a URL using an API.
5. Get the Cheapest Ticket — Searching for the cheapest available ticket.

Tools and Concepts
- Postman
- REST APIs
- HTTP methods (GET and POST)
- Query parameters and headers
- JSON responses
- HTTP status codes

Note: These tasks use existing APIs. No APIs were developed as part of this practice. API keys are not included in this repository.
